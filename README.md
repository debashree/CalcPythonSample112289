# Basic Calculator

A small desktop calculator written in Python with Tkinter. It supports:

- Addition, subtraction, multiplication, and division
- Modulo (`%`) and powers (`**`)
- Parentheses and decimal values
- Clear and backspace controls
- Enter to calculate and Escape to clear

## Run

From this folder, run:

```powershell
python calculator.py
```

Tkinter is included with most standard Python installations, so no third-party packages are required.
